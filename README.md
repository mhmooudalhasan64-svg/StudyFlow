# StudyFlow — رفيق طالب البكالوريا

تطبيق ويب تقدّمي (PWA) عربي بالكامل (RTL) لمساعدة طلاب البكالوريا على تنظيم الدراسة. يعمل دون خادم ودون اتصال بعد أول تحميل، وكل البيانات محفوظة في IndexedDB على جهاز الطالب.

## الميزات

- **خطة الدراسة**: مهام لكل يوم مع المادة والمدة، شريط أسبوعي، ونقل المهام المتأخرة لليوم.
- **مؤقت التركيز (بومودورو)**: تركيز/استراحة قصيرة/طويلة بمدد قابلة للتعديل، يستمر عند التنقل بين الصفحات، يحفظ الجلسات تلقائياً حسب المادة، مع تنبيه صوتي وإشعار.
- **العدّ التنازلي للامتحانات**: عدد الأيام المتبقية لكل امتحان.
- **بنك الأسئلة والاختبارات**: اختبارات سريعة بحسب المادة، مراجعة الأخطاء، إضافة أسئلتك، استيراد/تصدير JSON.
- **الإحصاءات والتحفيز**: هدف يومي، سلسلة أيام متتالية، مخطط أسبوعي، وقت لكل مادة، دقّة الأسئلة، وأوسمة.
- **المستشار الدراسي** (صفحة «المساعد»): يولّد خطة مراجعة لأسبوع حسب قرب الامتحانات والمواد المهملة وهدفك اليومي، وينبّه لما يحتاج انتباهاً. يعمل محلياً ودون إنترنت.
- **مساعد محادثة اختياري** (Grok/xAI) عبر دالة `api/chat.ts` على Vercel؛ يحتاج متغير `XAI_API_KEY` في إعدادات Vercel، وبدونه تعمل بقية الميزات كالمعتاد.
- **قسم البكالوريا السورية** (`#/bac`): فرعان مستقلان (علمي وأدبي) مع اختيار الصف، تُضاف مواد الفرع تلقائياً عند اعتماده، وتظهر نسبة إنجاز كل مادة.
- **مكتبة الكتب المدرسية**: كتب PDF مرتبة حسب المادة والوحدة والدرس، مخزنة في IndexedDB وتُفتح دون إنترنت.
- **بنك أسئلة البكالوريا**: الأسئلة تقبل وحدة وسنة ودورة، مع تصفية حسب المادة والوحدة والسنة وتصحيح فوري.
- **خطة إنهاء المنهاج**: وحدات ودروس ونسبة إنجاز لكل مادة وللمجموع.
- **المراجعة الذكية**: عند إنجاز درس يُجدول له سلّم مراجعة (افتراضياً 1، 3، 7، 14، 30 يوماً) قابل للتعديل.
- **البطاقات التعليمية** (تعريفات، تواريخ، مصطلحات، قواعد) بنفس سلّم المراجعة.
- **محاكي الامتحان النهائي**: نموذج بوقت محدد، ثم النتيجة والإجابات والأخطاء.
- **حاسبة العلامات**: مجموع ونسبة وهدف مطلوب حسب مواد الفرع. العلامة العظمى لكل مادة قابلة للتعديل (الافتراضي 100)، فأدخل التوزيع الرسمي لفرعك وصفّك.
- **نظام الإنجازات**: XP ومستويات وشارات، و**تقارير أسبوعية** (آخر 7 أيام أو الأسبوع الذي قبله) قابلة للنسخ والطباعة.
- **العمل دون إنترنت**: مؤشر انقطاع الاتصال، حالة التخزين، وتصدير/استعادة نسخة احتياطية (بدون ملفات PDF). لا مزامنة سحابية بعد لعدم وجود حسابات.
- وضعان داكن وفاتح بنمط «Future Tech».

> أسئلة بنك الأسئلة الأولية أمثلة بسيطة للتجربة فقط؛ احذفها أو استبدلها بأسئلة منهاجك.

## التشغيل

```bash
npm install
npm run icons    # مرة واحدة: يولّد أيقونات PWA (PNG) من public/icon.svg
npm run dev      # للتطوير
npm test         # الاختبارات (Vitest)
npm run build    # بناء الإنتاج (يولّد الأيقونات تلقائياً)
npm run typecheck # فحص TypeScript
npm run preview  # معاينة نسخة الإنتاج
```

لتجربة التثبيت على الهاتف شغّل `npm run build && npm run preview` وافتح العنوان من الجهاز (يتطلب HTTPS أو localhost لتفعيل خدمة العمل دون اتصال).

## التقنيات

React + TypeScript + Vite، Tailwind CSS، Lucide React، Dexie.js (IndexedDB)، Zustand، vite-plugin-pwa، Vitest + React Testing Library.

## البنية

```
src/
  db.ts            مخطط Dexie والأنواع
  seed.ts          بيانات أول تشغيل (المواد، الإعدادات، أسئلة تجريبية)
  store.ts         حالة Zustand + عمليات القراءة/الكتابة + منطق المؤقت
  lib/             أدوات مساعدة نقية (تواريخ، إحصاءات، مؤقت، استيراد/تصدير)
  components/      مكوّنات مشتركة
  pages/           الرئيسية، الخطة، المؤقت، الامتحانات، الأسئلة، الإحصاءات، الإعدادات،
                   البكالوريا، المكتبة، المنهاج، المراجعة، البطاقات، المحاكي، الحاسبة، الإنجازات، التقارير
```

## ملاحظات

- لا يُستخدم localStorage للبيانات الأساسية؛ كل شيء في IndexedDB.
- لم يُضَف Playwright بعد؛ يمكن إضافته لاحقاً لاختبارات المتصفح الشاملة.
